# 简历字体与许可证

项目随附以下 Regular 字重，用于在线预览、PDF 渲染与 DOCX 字体嵌入：

| 编辑器名称 | 字体文件 | 固定版本 | 许可证 |
| --- | --- | --- | --- |
| 现代黑体 | Source Han Sans SC | 2.005R | SIL Open Font License 1.1 |
| 经典宋体 | Source Han Serif SC | 2.003R | SIL Open Font License 1.1 |
| 雅致文楷 | LXGW WenKai | 1.522 | SIL Open Font License 1.1 |
| 简洁仿宋 | Zhuque Fangsong | 0.212 technical preview | SIL Open Font License 1.1 |

各字体的完整许可证文本位于 `public/fonts/OFL-*.txt`。字体可随应用及生成的文档嵌入和再分发，但不可脱离软件单独销售；修改字体时还应遵守许可证中的保留字体名称条款。
